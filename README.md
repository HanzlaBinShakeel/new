# Rateb Y. Rabie, KCHS — Modern Website

A redesigned, modern single-page website for [Rateb Y. Rabie, KCHS](https://rateb.rabie.us/), featuring smooth animations, responsive layout, and content sourced from the original site.

## Tech Stack

- React 18 + Vite
- Framer Motion (animations)
- CSS Modules

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Sections

- Hero carousel with parallax backgrounds
- About & Biography
- Mission pillars & FAQ
- Organizations (HCEF, KTH, JPI)
- Animated statistics
- Career highlights & events
- Full CV & awards
- Articles grid (links to original posts)
- Donation form (redirects to HCEF)
- Contact & newsletter
